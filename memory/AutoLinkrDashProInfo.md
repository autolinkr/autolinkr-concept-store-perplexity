## 4. Feature List (Consolidated)

- **4K + 1080P Dual Recording** — Front in true 4K UHD, rear in 1080P FHD, simultaneous and continuous.
- **STARVIS 2 Sensor + WDR/HDR** — Designed for low-light clarity; large F1.5/F1.8 aperture combo for maximum light intake.
- **170° / 140° Wide-Angle Dual View** — Minimizes blind spots, captures more of the scene.
- **Built-in GPS** — Embeds location, speed, and route into footage (visible on playback).
- **Built-in WiFi** — Connects to app for wireless viewing, downloading, and sharing.
- **OTA Firmware Updates** — Wireless software upgrades over WiFi.
- **Automatic Loop Recording** — Oldest footage overwritten when storage fills; no manual cleanup.
- **G-Sensor Impact Lock** — Detects sudden collisions and auto-locks the relevant clip so it's not overwritten.
- **24H Parking Monitor Mode** — Motion + impact triggered 15s clip recording when parked. Time-lapse mode for continuous low-power monitoring. **Requires hardwire kit (sold separately).**
- **Night Vision** — Combined IR + STARVIS 2 for after-dark recording.
- **App Control (iOS + Android)** — Wireless operation, sharing to friends or insurance.
- **Motion Detection**
- **3.18″ IPS Screen** — On-device playback and menu; can be set to sleep / turn off while recording continues.

### 6.2 What frustrates customers (objections to address)

| Pain point | Severity | Implication for AutoLinkr page |
|---|---|---|
| **WiFi connectivity is finicky** | **Most common complaint** | Must manually re-enable WiFi each car start; only one phone at a time; drops mid-use. Address head-on in FAQ + position our app as the upgrade. |
| **App quality, especially iOS** | High | REDTIGER's iOS app reportedly 2.2★ on the App Store. One reviewer's solve: never use "Login with Apple/Google" — use email signup. We need a better app experience or set very clear expectations. |
| **Small screen** | Medium | 3.18″ is "unobtrusive" to some, "barely usable" to others. Frame as unobtrusive intentionally — playback happens on phone. |
| **12V power plug looseness** | Medium | Plug pops out with vibration → no recording. Multiple reports. Consider including a tighter plug or recommending hardwire. |
| **Hardwire kit sold separately** | Medium | Customers expect parking mode to "just work" out of the box. Either bundle the kit or be explicit that it's an add-on. |
| **64GB SD card too small** | Medium | Most upgrade to 256GB. Either ship with 128GB+ or recommend the upgrade clearly. |
| **Adhesive mount peeling** | Lower | Pad separated from mount in some cases; resolved by support sending replacements. Reinforced adhesive or backup pads in-box would address. |
| **Instructions outdated / unclear** | Lower | One reviewer noted REDTIGER admitted manual is "outdated, 4 years old." **Easy win: ship a clear, current quick-start guide.** |
| **Cigarette lighter plug** | Lower | Some prefer USB-only power; some have only one cig socket. |
| **Cable length on rear cam** | Mixed | "Generous" to most; "too long, hard to hide" to some; "too short for swing-door SUVs" (RAV4) to a few. Pattern: longer is better, with optional extension for big vehicles. |
| **Quality control / DOA units** | Lower (long tail) | Several "came broken" or "stopped working after a year" reviews. AutoLinkr's warranty + return story needs to be airtight. |

## 7. Page Copy Implications (early read)

### Lead with
1. **4K front + 1080P rear, STARVIS 2 sensor** — the headline tech.
2. **License-plate clarity day and night** — most-cited proof point in reviews.
3. **Built-in WiFi + GPS** — modern, connected.
4. **24H parking monitor** — passive protection while parked.
5. **60-second-ish install** — match the AutoLinkr brand promise of effortless setup.

### Objections to handle on-page
- "Will the WiFi/app actually work?" → highlight AutoLinkr-branded app + setup instructions; explicit FAQ entry.
- "Is parking mode included?" → be transparent: parking mode requires the hardwire kit. Offer it as a bundle.
- "Will it fit my vehicle?" → universal 12–24V, lean on the real-vehicle list above.
- "Is the SD card big enough?" → ship with 128GB+ if possible, or recommend the 256GB upgrade visibly.
- "What if it breaks?" → AutoLinkr 30-day money-back + lifetime support standard pattern.

### Positioning differentiators vs REDTIGER (where we can win)
- **Better app experience** (REDTIGER's iOS app is a real weak point).
- **Clear, current instructions** (their manual is 4 years stale per their own support).
- **Hardwire kit + larger SD bundled** (removes the #1 "wish I'd known" complaint).
- **AutoLinkr brand voice + design** — premium, intentional, drives-confident-customers — vs REDTIGER's generic listing aesthetic.
- **Tighter 12V plug or USB-C power option** (if sourceable from supplier).
